Comment mettre votre site en ligne GRATUITEMENT ?

Suivez ces 3 étapes très simples pour publier votre site internet sur Google gratuitement et sans abonnement !

1 Enregistrer le code sur votre ordinateur

Copiez tout ce code HTML, ouvrez le Bloc-notes (sur Windows) ou TextEdit (sur Mac), collez-y le code, puis enregistrez le fichier sous le nom exact : index.html.

2 Glisser-déposer sur Netlify Drop

Rendez-vous gratuitement sur le site app.netlify.com/drop et faites simplement glisser votre fichier index.html sur la zone prévue.

3 Votre site est en ligne !

En moins de 5 secondes, Netlify vous génère un lien web gratuit (ex: mon-gite-provence.netlify.app) que vous pouvez envoyer à vos clients ou lier à vos cartes de visite !

Astuce : Connecter Formspree pour recevoir les demandes par email !

Pour que le formulaire de réservation vous envoie un e-mail direct, créez un compte gratuit sur Formspree.io et remplacez simplement l'attribut action dans le formulaire !
