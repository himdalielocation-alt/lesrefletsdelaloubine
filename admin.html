Photos du site

Les Reflets de la Loubine — glissez une photo sur un emplacement, elle est réduite automatiquement puis mise en ligne. Voir le site

Connexion

Comment obtenir ma clé ? (une seule fois, 2 minutes)
  1. Sur ordinateur, connectez-vous à github.com avec le compte du site.
  2. Ouvrez github.com/settings/personal-access-tokens/new.
  3. Token name : « Photos du site ». Expiration : 1 an (vous en recréerez une ensuite).
  4. Repository access : « Only select repositories », puis choisissez lesrefletsdelaloubine.
  5. Permissions → Repository permissions → Contents : « Read and write ». Ne touchez à rien d'autre.
  6. Cliquez sur Generate token, copiez la clé affichée et collez-la ci-dessus.

La clé reste enregistrée uniquement dans le navigateur de cet appareil. Ne l'utilisez pas sur un ordinateur partagé, et ne la communiquez à personne. En cas de doute, supprimez-la sur la même page GitHub : elle cesse aussitôt de fonctionner.

✓ Connecté. Vous pouvez envoyer des photos.

Emplacements photo

Comment ça marche : glissez une photo sur un emplacement, ou touchez-le pour choisir une photo de votre téléphone ou ordinateur. Pour remplacer une photo, renvoyez-en simplement une autre au même endroit.

Après chaque envoi, le site se met à jour tout seul en 2 à 3 minutes (rechargez la page du site pour voir le résultat). Conseil : photos à l'horizontale, bien éclairées, de jour.
